# Brainlist — Portfólio & Dashboard Pessoal

Aplicação web e portfólio pessoal desenvolvido com **React 19**, **TypeScript** e **Tailwind CSS**.

O projeto começou como um dashboard simples em HTML/CSS feito na primeira semana da faculdade (FIAP - Análise e Desenvolvimento de Sistemas) e foi reconstruído como uma Single Page Application moderna com carrossel interativo e showcase de projetos.

## O que tem no projeto

### 1. Sobre Mim
- Apresentação profissional e atuação atual na **WPP Commerce** (Salesforce Marketing Cloud na conta Nestlé).
- Tecnologias principais: `JavaScript`, `Java`, `Python`, `SQL`, `HTML`, `React`, `Node` e `Manipulação de IA Generativa`.
- Botão para download direto do currículo em PDF (`curriculo-carlos-chiarelli.pdf`).
- Assistente com respostas diretas sobre histórico técnico e formação.

### 2. Projetos em Destaque
Grid responsivo com filtros por categoria (`Todos`, `IA & DevTools`, `Full Stack & Java`, `Jogos & Web`, `Cápsula / Memorando`):
1. **TokenPulse:** Monitor de consumo de tokens em tempo real, consulta de cotas da Google Gemini API e proxy local compatível com OpenAI.
2. **FinançasPRO:** Painel financeiro pessoal e carteira de investimentos (Ações, FIIs e Renda Fixa) com sincronização local via QR Code.
3. **PokéCrowlers:** Roguelike RPG em turnos com masmorras 3D procedurais no universo Pokémon.
4. **Sistema de Triagem Hospitalar:** Aplicação Java OOP para classificação de risco e triagem clínica de pacientes.
5. **Backlog de Jogos:** Dashboard com persistência em LocalStorage e sorteador aleatório de jogos.
6. **Pedra, Papel ou Tesoura:** Jogo interativo com manipulação de DOM hospedado na Vercel.
7. **Adivinhação de Números:** Jogo com geração randômica e controle de tentativas na Vercel.
8. **Brainlist v1.0 (Memorando):** Visualizador da versão original da Semana 1 em iframe interativo.

### 3. Plano de Estudos & Calendário
- Calendário de Novembro de 2026 com navegação por dias.
- Lista de tarefas diárias salvas automaticamente no `localStorage`.
- Sugestão rápida de cronogramas por matéria.

### 4. Ideias
- Bloco de notas rápido com persistência local para registrar ideias de projetos e estudos.

### 5. Arquivos Originais (`/legacy`)
- O código original em HTML, CSS e JS puro da 1ª semana de faculdade segue preservado intacto na pasta `legacy/`.

## Como rodar o projeto

```bash
# 1. Instalar as dependências
npm install

# 2. Iniciar o servidor de desenvolvimento
npm run dev

# 3. Gerar a build de produção
npm run build
```
