## Funcionalidades e Arquitetura

* **Perfil & Rigor Analítico:** Destaque para operações de CRM em escala global (**Salesforce Marketing Cloud**) na **WPP Commerce / Conta Nestlé**, engenharia de requisitos e modelagem orientada a objetos.

* **Assistente do Portfólio:** Módulo interativo que sintetiza respostas rápidas para recrutadores e visitantes sobre o histórico técnico do Carlos.

### 2. Galeria de Projetos com Screenshots Reais
Filtros interativos por categoria (`Todos`, `IA & DevTools`, `Full Stack & Java`, `Jogos & Web`, `Cápsula / Memorando`) com grid responsivo em 3 colunas e scroll suave:
1. **TokenPulse — Monitor de Cotas IA:** Cockpit de alto desempenho para monitorar consumo de tokens em tempo real, consulta de cotas oficiais da Google Gemini API e proxy reverso local compatível com OpenAI.
2. **FinançasPRO — Gestão Financeira & Investimentos:** Painel financeiro pessoal e carteira de ativos (Ações, FIIs e Renda Fixa) com acompanhamento de lucros e proventos, sincronização móvel via QR Code na rede Wi-Fi local, modo privacidade e alarmes sonoros.
3. **PokéCrowlers — Roguelike RPG 3D:** Jogo de exploração procedural de masmorras em 3D e combates por turnos ambientado no universo Pokémon, com Pokédex, evolução de níveis e save mobile.
4. **Sistema de Triagem Hospitalar:** Aplicação em Java com regras estritas de dor e sintomas clínicos baseada em arquitetura orientada a objetos (OOP).
5. **Backlog de Jogos & Sorteador:** Dashboard com persistência no LocalStorage e algoritmo de sorteio aleatório com capas.
6. **Pedra, Papel ou Tesoura:** Lógica clássica com manipulação de DOM e jogadas randômicas hospedado na Vercel.
7. **Jogo de Adivinhação de Números:** Motor de números randômicos com controle de tentativas hospedado na Vercel.
8. **Brainlist v1.0 — Cápsula do Tempo / Memorando:** Dashboard original da Semana 1 de ADS na FIAP preservado com live preview interativo.

## Como Executar Localmente

### 1. Clonar o repositório
```bash
git clone https://github.com/carlostsucamoto/brainlist.git
cd brainlist
```

### 2. Instalar dependências
```bash
npm install
```

### 3. Rodar em ambiente de desenvolvimento
```bash
npm run dev
```
Acesse no navegador: `http://localhost:5173`

### 4. Gerar build de produção
```bash
npm run build
```
Os arquivos otimizados e prontos para deploy estarão na pasta `dist/`.
